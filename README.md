One original funny line about everyday life (103 characters):

> My printer only jams when I'm in a hurry, which is suspicious, because the printer is never in a hurry.

The setup is a truth everyone recognises — the printer only ever jams at the worst possible moment. The punchline turns the suspicion back on the accuser: the printer cannot be plotting against you, because it is never in a hurry in the first place. One sentence, no filler, the surprise lands on the last word.
